## 3. Theoretical Foundation

### The Kuramoto Model

The Kuramoto model (1975) describes synchronization in populations of coupled oscillators:

```
THE KURAMOTO EQUATION
═════════════════════

dθᵢ/dt = ωᵢ + (K/N) Σⱼ sin(θⱼ - θᵢ)

Where:
  θᵢ = phase of oscillator i
  ωᵢ = natural frequency of oscillator i
  K  = coupling strength
  N  = number of oscillators
```

When coupling strength K exceeds a critical threshold Kc, the system undergoes a **phase transition** from incoherence to synchronization.

### Application to Collective Intelligence

| Order parameter ℜ | Group coherence |

```
ORDER PARAMETER (RESONANCE CONSTANT)
════════════════════════════════════

ℜ e^(iΨ) = (1/N) Σⱼ e^(iθⱼ)

Where:
  ℜ ∈ [0, 1] = magnitude (synchronization strength)
  Ψ = collective phase (group "direction")

ℜ = 0 → Complete incoherence (random phases)
```

## 5. Kuramoto Oscillator Implementation

The Neuroresonance implementation in Luci Browser uses the following Rust structures:

### Oscillator State

```rust
pub struct OscillatorState {
    pub phase: f32,           // Current phase (0 to 2π)
    pub natural_freq: f32,    // Natural frequency (Hz)
    pub amplitude: f32,       // Oscillation amplitude
    pub last_update: DateTime<Utc>,
}

impl OscillatorState {
    pub fn update(&mut self, dt: f32, coupling_force: f32) {
        // Kuramoto equation: dθ/dt = ω + K*Σsin(θ_j - θ_i)
        let phase_velocity = self.natural_freq + coupling_force;
        self.phase += phase_velocity * dt;
        self.phase = self.phase.rem_euclid(TAU); // Wrap to [0, 2π]
    }

    pub fn get_resonance(&self, other: &OscillatorState) -> f32 {
        // cos(θⱼ - θᵢ) normalized to [0, 1]
        let phase_diff = other.phase - self.phase;
        (phase_diff.cos() + 1.0) / 2.0
    }
}
```

### Network Dynamics

```rust
pub struct NeuroResonanceNetwork {
    oscillators: HashMap<Uuid, NeuralOscillator>,
    global_phase: f32,
    order_parameter: f32, // ℜ: synchronization measure
}

impl NeuroResonanceNetwork {
    pub fn step(&mut self, dt: f32) {
        // Update all oscillators
        for (id, oscillator) in &mut self.oscillators {
            let coupling_force = self.calculate_total_coupling(id);
            oscillator.state.update(dt, coupling_force);
        }
        
        // Update global order parameter ℜ
        self.update_order_parameter();
    }

    fn update_order_parameter(&mut self) {
        // ℜ e^(iΨ) = (1/N) Σ e^(iθⱼ)
        let n = self.oscillators.len() as f32;
        let (real_sum, imag_sum) = self.oscillators.values()
            .map(|osc| (osc.state.phase.cos(), osc.state.phase.sin()))
            .fold((0.0, 0.0), |(r, i), (cr, ci)| (r + cr, i + ci));
        
        self.order_parameter = ((real_sum/n).powi(2) + (imag_sum/n).powi(2)).sqrt();
        self.global_phase = (imag_sum/n).atan2(real_sum/n);
    }
}
```

```javascript
mutate(mutationRate = 0.1, strength = 0.2) {
    this.genes.forEach(gene => {
        if (Math.random() < mutationRate) {
            gene.value += (Math.random() - 0.5) * strength * (gene.max - gene.min);
            gene.value = Math.max(gene.min, Math.min(gene.max, gene.value));
        }
    });
}
```

**Crossover:**
```javascript
crossover(partner, method = 'blend') {
    const child = new NeuralGenome();
    this.genes.forEach((gene, name) => {
        const partnerGene = partner.genes.get(name);
        const blendRatio = Math.random();
        child.genes.get(name).value = 
            gene.value * blendRatio + partnerGene.value * (1 - blendRatio);
    });
    return child;
}
```

## Appendix A: Mathematical Derivation of Critical Coupling

For identical oscillators with frequency distribution g(ω), the critical coupling strength is:

```
Kc = 2 / (π * g(0))
```

For a Lorentzian distribution with half-width γ:

```
g(ω) = γ / (π * (ω² + γ²))
g(0) = 1 / (πγ)
Kc = 2πγ
```
